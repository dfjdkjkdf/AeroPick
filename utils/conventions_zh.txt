#项目约定词表（航天控制软件需求的通用写法；适用于本项目所有任务）
1. 位域记法：X(Dn) 表示变量 X 的第 n 位（D0 为最低位）。"X(Dn)=1" 即 ((X >> n) & 1) == 1，不是 X == 1。
2. 布尔标志：上下文定义了 TRUE32/FALSE32 时，标志"=1/=0"分别指 TRUE32(0xEB90146F)/FALSE32(0)。有效/无效等标志的取值以上下文中的宏为准（如 VALID、INVALID 的具体数值）。
3. 取模：需求中的 mod(x, a) 指 ModPNHP(x, a)，结果落在 (−a, a]、周期为 2a（例：mod(4, π) = 4 − 2π）；不是 C 的 fmod。需要落在 [0, P) 时用 ModZ2P(x, P)。
4. 符号函数：sgn(x) 指 Sgn2：x ≥ 0 取 1，x < 0 取 −1（sgn(0) = 1）。
5. 限幅：mlf(x, b)、"限幅到 b" 指对称限幅 LimitDouble(x, b)，结果在 [−b, b]。
6. 坐标转换阵：Rx/Ry/Rz 为坐标变换（被动）矩阵，如 Rx(a) = [[1,0,0],[0,cos a,sin a],[0,−sin a,cos a]]；姿态阵 C_ba 把 a 系分量变换到 b 系。
7. 四元数：库函数 C2Q/Q2C 中四元数的标量部分在最后（q[3]）。
8. 矩阵求逆：MatrixInv33 成功返回 1，矩阵奇异返回 0。
9. 周期调用：函数每个控制周期被调用一次。"上一拍/上一周期的值"指上一次调用后保存的值；"连续 N 次/N 拍"指连续 N 次调用；状态机每次调用只推进一步，除非需求写明在同一拍内继续执行下一步。
10. 角度单位：需求未特别说明时计算一律用弧度；度与弧度用 DEG2RAD/RAD2DEG 换算；库中 EARTH_R 单位为米。
